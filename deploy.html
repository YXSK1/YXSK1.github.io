📦 第一步：下载代码

将整个文件夹下载到电脑，你会看到这些文件：

  • index.html - 顾客点餐页
  • admin.html - 商家后台
  • qrcode.html - 二维码生成器
  • styles.css - 样式文件
  • data.js - 数据层
  • app.js - 顾客端逻辑
  • admin.js - 后台逻辑

🐙 第二步：上传到 GitHub

  1. 打开 github.com 注册/登录
  2. 点击右上角 "+" → "New repository"
  3. 仓库名填 bbq-order，选 Public，点 Create
  4. 在仓库页面点 "uploading an existing file"
  5. 把整个文件夹的所有文件拖进去，点 "Commit changes"

🌐 第三步：开启 GitHub Pages

  1. 进入仓库 → Settings → Pages
  2. Source 选 "Deploy from a branch"
  3. Branch 选 "main" → 点 Save
  4. 等待约1分钟，你会获得一个网址：
    https://你的用户名.github.io/bbq-order/
  5. 打开 qrcode.html，填入上面的网址，生成二维码！
⚠️ 重要提醒

GitHub Pages 是公开网址，任何人都能访问。
但这套系统数据存在浏览器本地（LocalStorage），
所以顾客和商家的数据是分开的，互不影响。
商家后台只需在你自己的电脑/平板上打开即可。

☁️ 腾讯云 COS 静态网站

  1. 打开 cloud.tencent.com/product/cos 注册登录
  2. 创建存储桶（Bucket），名称随意，地区选离你近的
  3. 将全部文件上传到存储桶根目录
  4. 开启"静态网站"功能，得到访问地址
  5. 腾讯云 COS 有免费额度，个人小店基本够用

🏠 局域网方案（最简单）

适合：小店只有几张桌子，不打算做外卖

  1. 用一台电脑（笔记本/台式）放在店里，连上WiFi
  2. 双击打开 index.html 和 admin.html
  3. 在同一WiFi下，手机浏览器访问电脑的IP地址
  4. 查看电脑IP：Windows按Win+R输入cmd，执行ipconfig
  5. 手机访问 http://192.168.x.x:端口 即可点餐

缺点：电脑关机后无法访问，仅适合简单场景

🚀 上线后日常使用流程

  1. 开店时：电脑/平板打开 admin.html → 确认店铺状态为"营业中"
  2. 顾客到店：扫桌上的二维码 → 浏览菜单 → 加入购物车
  3. 选择堂食/外卖：堂食填桌号，外卖填地址和电话
  4. 提交订单：弹出收款码 → 顾客截图 → 微信/支付宝扫码转账
  5. 商家收到：后台实时弹窗+声音提醒 → 确认接单 → 开始制作
  6. 完成后：点击"完成订单" → 顾客可查看状态

⚙️ 首次配置清单

  1. 打开 admin.html → 【💰 收款设置】→ 上传微信/支付宝收款码
  2. 【🍽️ 菜品管理】→ 修改菜品名称、价格，添加/删除菜品
  3. 【⚙️ 店铺设置】→ 修改店铺名称，确认营业状态
  4. 打开 qrcode.html → 生成专属二维码 → 打印张贴
  5. 测试：手机扫码 → 下单 → 确认后台能收到提醒
💡 进阶建议

• 用iPad当商家后台，放收银台，随时查看订单
• 收款码建议用微信/支付宝商家收款码（支持信用卡付款）
• 定期在后台【清空订单】保持数据整洁
• 如需数据跨设备同步，可后续接入云数据库（如腾讯云开发）
