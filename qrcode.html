🔥 二维码生成

生成专属点餐二维码 · 打印张贴即可

📋 使用步骤

1. 点击下方"生成二维码"按钮
2. 将二维码图片保存到手机/电脑
3. 打印出来贴在桌子上 / 门口 / 外卖包装上
4. 顾客扫码即可进入点餐页面

💡 部署提示：
1. 将整个文件夹上传到 GitHub Pages（免费）或 腾讯云 COS（有免费额度）
2. 获取你的网页地址，填入上方输入框
3. 生成二维码后打印，每个桌子贴一张
4. 顾客扫码 → 点餐 → 转账付款 → 你在后台收到订单
