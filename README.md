# 🔥 烧烤店自助点餐系统

## 功能概览

### 顾客端
- 扫码进入点餐页面
- 分类浏览：🔥烧烤类 | 🍟小吃类 | 🥤酒水类
- 购物车（添加/删除/备注）
- 支持堂食 + 外卖（填写地址/电话）
- 提交订单后展示收款码（微信/支付宝）
- 线下转账付款，零手续费

### 商家后台
- 实时订单弹窗 + 声音提醒
- 订单状态管理（新订单/制作中/已完成）
- 菜品管理（增删改查、价格修改）
- 营业状态开关
- 查看收款码设置

## 技术架构
- 纯前端 HTML/CSS/JS，无需服务器
- 使用 LocalStorage 持久化数据
- 通过 BroadcastChannel 实现跨标签页实时通信
- 生成专属二维码（可打印）

## 使用方式
1. 用浏览器打开 `index.html` → 顾客点餐
2. 用浏览器打开 `admin.html` → 商家后台
3. 用 `qrcode.html` 生成专属二维码
4. 将文件部署到免费托管（如 GitHub Pages / 腾讯云静态网站）

## 部署建议
- 推荐：GitHub Pages（免费）或 腾讯云 COS 静态网站（免费额度）
- 也可直接局域网使用（同一WiFi下手机访问电脑IP）
